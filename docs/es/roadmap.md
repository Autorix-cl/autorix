# Hoja de Ruta Técnica de Autorix (Roadmap)

Estado de desarrollo y próximas fases para el ecosistema **Autorix Zero-Trust IAM**.

---

## 🎯 Fases Completadas (v1.0)

- [x] **Nexus (Zanzibar ReBAC)**: Tuplas de relaciones, detección de ciclos, evaluación de sub-5ms y compilador APL.
- [x] **Themis (ABAC CEL)**: Evaluación basada en atributos, anillos de prioridad y Google CEL.
- [x] **Ego (Identidad)**: Traits dinámicos, Argon2id, MFA TOTP RFC 6238, Flow State-Machine y WebAuthn.
- [x] **Janus (OAuth2 / OIDC)**: Rotación automática de claves RS256 JWKS, PKCE y retos desacoplados de Login/Consentimiento.
- [x] **Aegis (Proxy PEP)**: Pipeline de 4 etapas perimetral con reglas declarativas.
- [x] **Vulcan (Macaroons)**: API keys con prefijos reconocibles y atenuación descentralizada de caveats.
- [x] **Hermes (SAML/SCIM)**: Federación SAML 2.0 Web SSO y sincronización continua SCIM 2.0.
- [x] **Argus (Plano de Control)**: Registro de flota, tokens de enrolamiento y cadena inmutable de auditoría SHA-256.
- [x] **Console (Next.js 15)**: 9 Studios de administración dedicados y verificación en vivo.
- [x] **Soporte Multi-Idioma (i18n)**: Documentación completa en Inglés y Español con selector de idioma en VitePress.
