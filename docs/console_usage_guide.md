# Administer your Autorix cluster using the Console

Autorix Console is the enterprise web interface and Backend-for-Frontend (BFF) layer for the Autorix Zero-Trust IAM Suite. It provides real-time cluster telemetry, interactive engine management studios, cryptographic audit log verification, compliance monitoring, and fleet orchestration.

### Quick path

1. Open your browser to `http://localhost:3000`. You will be directed to `/setup`.
2. Enter the one-time `abt_...` secret generated by Argus (found in container startup logs).
3. Enter your Name, Work Email, and Master Password.
4. Click **Initialize Cluster Owner** to create the root administrator and lock the cluster.
5. Once claimed, you will be redirected to `/login` to log in as the Operator.

### Details

#### Architecture & Security Model
Autorix Console uses a Next.js 15 App Router architecture with a secure Backend-for-Frontend (BFF) proxy.
* **Isolated Standalone Auth Shell**: Routes like `/login`, `/setup`, `/session-expired`, and `/403` render in a dedicated security shell isolated from the dashboard layout.
* **Automatic Bootstrap Redirection**: If no root owner exists, requests are automatically redirected to the Initial Bootstrap Wizard (`/setup`).
* **Double-Submit CSRF & Secure Cookies**: All mutating BFF requests enforce matching `autorix_csrf` cookies and `X-CSRF-Token` headers. Sessions use HTTP-only, SameSite cookies (`autorix_session`).

#### Studio Workspaces
The Console provides dedicated workspaces for every component:
* **Identities Studio** (`/identities`): Manage users, dynamic JSON Schema traits, reset passwords, inspect MFA status (Autorix Ego).
* **API Keys Studio** (`/api-keys`): Issue keys, interactively add Macaroon caveats, generate capability tokens (Autorix Vulcan).
* **Permissions Studio** (`/permissions`): Zanzibar relation graph visualizer, Check evaluation simulator, relation tuple CRUD (Autorix Nexus).
* **Proxy Rules Studio** (`/proxy-rules`): Route rules editor, PEP authenticators/authorizers/mutators, live dry-run tester (Autorix Aegis).
* **Policies Studio** (`/policies`): Google CEL editor with syntax highlighting, priority ranking rings, test fixtures (Autorix Themis).
* **Enterprise Studio** (`/enterprise`): SAML 2.0 IdP metadata management, SCIM 2.0 directory sync monitoring (Autorix Hermes).
* **Fleet Studio** (`/fleet`): Engine health status, latency graphs, topology visualization, `aet_` token minter (Autorix Argus).
* **Audit Trail Studio** (`/audit`): Search audit records, JSON diffs, one-click SHA-256 Merkle chain verification, CSV export (Autorix Argus).
* **Compliance Studio** (`/compliance`): Real-time SOC 2 Type II (CC6.1/CC6.2) and ISO 27001 evidence dashboards (Autorix Argus).

#### Live Merkle Audit Verification
The Audit Studio (`/audit`) directly queries Argus and provides a zero-mock cryptographic verification button:
* Computes the SHA-256 hash across all linked records in PostgreSQL.
* Confirms that no record has been tampered with, deleted, or injected out of order.
* Provides one-click export for external SOC 2 and ISO 27001 auditors.
