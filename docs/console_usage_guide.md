# Autorix Console: Administration & Studio User Guide

**Autorix Console** is the enterprise web interface and Backend-for-Frontend (BFF) layer for the Autorix Zero-Trust IAM Suite. Built with **Next.js 15 App Router**, React 19, and Tailwind CSS, it provides real-time cluster telemetry, interactive engine management studios, cryptographic audit log verification, compliance monitoring, and fleet orchestration.

---

## 🏛️ 1. Architecture & Security Model

```text
       [ Browser / Operator ] ─── HTTPS/WSS ───► [ Autorix Console (:3000) ]
                                                        │
                      ┌─────────────────────────────────┴─────────────────────────────────┐
                      ▼ (BFF Proxy & Double-Submit CSRF Protection)                       ▼
             [ Argus Control Plane ]                                             [ IAM Engines ]
             - Operators & Sessions                                              - Nexus Zanzibar Studio
             - Merkle Hash Chained Audit Log                                     - Ego Identity Studio
             - Continuous Compliance Evidence                                    - Janus OIDC Studio
             - SSE Stream & Real-time Alerts                                     - Aegis PEP Proxy Studio
                                                                                 - Vulcan Key Studio
                                                                                 - Hermes SAML/SCIM Studio
                                                                                 - Themis Policy Studio
```

### Security Guarantees

1. **Isolated Standalone Auth Shell**:
   - Routes like `/login`, `/setup`, `/session-expired`, and `/403` render in a dedicated security shell completely isolated from the dashboard layout, sidebar, and internal navigation.
2. **Automatic Bootstrap Redirection**:
   - If no root owner exists (`/api/auth/status` returns `bootstrapped: false`), any request is automatically redirected to the **Initial Bootstrap Wizard** (`/setup`).
   - Once claimed, `/setup` redirects directly to `/login`.
3. **Double-Submit CSRF & Secure Cookies**:
   - All mutating BFF requests (`POST`, `PUT`, `PATCH`, `DELETE`) enforce matching `autorix_csrf` cookies and `X-CSRF-Token` headers.
   - Sessions use HTTP-only, SameSite cookies (`autorix_session`).

## 🚀 2. Setup & Login Workflows

### 2.1 Initial Cluster Bootstrap Wizard (`/setup`)

1. Open browser at `http://localhost:3000`. You will be directed to `/setup`.
2. Enter the one-time `abt_...` secret generated by Argus (found in container startup logs).
3. Enter Name, Work Email, and Master Password.
4. Click **Initialize Cluster Owner** to create the root administrator and lock the cluster.

### 2.2 Operator Login (`/login`)

- **Break-Glass Local Operator**: Email and password with Argon2id verification and automated 15-minute lockouts after 5 failed attempts.
- **Enterprise SSO**: One-click federation via SAML 2.0 or OIDC through Hermes and Janus.

## 📜 4. Live Merkle Audit Verification

The Audit Studio (`/audit`) directly queries Argus and provides a zero-mock cryptographic verification button:
* Computes the SHA-256 hash across all linked records in PostgreSQL.
* Confirms that no record has been tampered with, deleted, or injected out of order.
* Provides one-click export for external SOC 2 and ISO 27001 auditors.
