# Autorix Console: Administration & Studio User Guide

**Autorix Console** is the enterprise web interface and Backend-for-Frontend (BFF) for the Autorix Zero-Trust IAM Platform. Built with **Next.js 15 App Router**, React 19, and Tailwind CSS, it provides real-time cluster telemetry, engine configuration studios, cryptographic audit log verification, compliance monitoring, and fleet management.

---

## 🏛️ Architecture & Security Model

```text
       [ Browser ] ─── HTTPS/WSS ───► [ Autorix Console (:3000) ]
                                              │
                     ┌────────────────────────┴────────────────────────┐
                     ▼ (BFF Proxy & Double-Submit CSRF Protection)     ▼
            [ Argus Control Plane ]                            [ IAM Engines ]
            - Operators & Sessions                             - Nexus Zanzibar Studio
            - Hash Chained Audit Log                           - Ego Identity Studio
            - Compliance Evidence                              - Janus OIDC Studio
            - Real-time Notifications                          - Aegis Proxy Studio
                                                               - Vulcan Key Studio
                                                               - Hermes SAML/SCIM Studio
                                                               - Themis Policy Studio
```

### Security Features

1. **Isolated Standalone Auth Shell**:
   - Routes like `/login`, `/setup`, `/session-expired`, and `/403` render in a dedicated, distraction-free security shell completely isolated from the dashboard sidebar, navigation, and internal header.
2. **Automatic Bootstrap Redirection**:
   - If no root administrator exists (`/api/auth/status` $\rightarrow$ `bootstrapped: false`), any visitor is automatically redirected to the **Initial Bootstrap Wizard** (`/setup`).
   - If the cluster has already been claimed, `/setup` redirects directly to `/login`.
3. **Double-Submit CSRF & Secure Cookies**:
   - All mutating BFF requests (`POST`, `PUT`, `PATCH`, `DELETE`) enforce matching `autorix_csrf` cookies and `X-CSRF-Token` headers.
   - Sessions are protected via HTTP-only, SameSite cookies (`autorix_session`).

## 🚀 Setup & Login Workflows

### 1. Initial Cluster Bootstrap Wizard (`/setup`)

When launching Autorix for the first time:
1. Navigate to `http://localhost:3000`. You will land on the **Initial Bootstrap Wizard**.
2. **Bootstrap Token**: Enter the one-time `abt_...` secret generated by Argus during startup (found in `docker logs autorix-argus`).
3. **Root Owner Profile**: Enter Full Name, Work Email, and Master Password (min. 8 characters).
4. Click **Initialize Cluster Owner**. This writes the root owner to `operators` and `operator_credentials` with Argon2id salted hashing and claims the cluster.

### 2. Operator Authentication (`/login`)

Autorix Console supports two authentication modes:
* **Break-Glass Operator**: Local administrative authentication with email and master password. Rate-limited and audited against lockout attacks.
* **Enterprise SSO**: SAML 2.0 / OIDC single sign-on federation through registered Hermes or Janus Identity Providers.

## 🛠️ Studio Walkthroughs

The Console includes dedicated Studio interfaces for each of the 7 IAM engines:

### 1. Identities Studio (`/identities` — Ego Engine)
* **User Management**: Create, search, edit, lock, and delete user identities.
* **Schema Inspection**: Dynamic JSON Schema trait validation (e.g. email, department, phone, profile metadata).
* **MFA & Credentials**: View TOTP enrollment status and reset recovery codes.

### 2. API Keys Studio (`/api-keys` — Vulcan Engine)
* **Key Vaulting**: Issue high-entropy keys with environment prefixing (`av_live_...` / `av_test_...`).
* **Macaroon Attenuation**: Interactively add HMAC-SHA256 caveats (time expiration, IP restrictions, method constraints, scope limits) and generate attenuated capability tokens locally.

### 3. Permissions Studio (`/permissions` — Nexus Engine)
* **Zanzibar Graph Explorer**: Create and inspect relation tuples (`namespace:object#relation@subject`).
* **Check Simulator**: Test authorization decisions in real-time with sub-millisecond graph traversals.

### 4. Proxy Rules Studio (`/proxy-rules` — Aegis Engine)
* **PEP Routing Rules**: Manage URL path patterns, HTTP methods, and upstream destinations.
* **Pipeline Config**: Configure authenticators (JWT, API key, session), authorizers (Zanzibar, Themis CEL), and mutators (header injection).
* **Rule Tester**: Simulate incoming requests to test rule matching before deploying to the reverse proxy.

### 5. Policies Studio (`/policies` — Themis Engine)
* **CEL Editor**: Author ABAC policies in Google Common Expression Language with syntax highlighting.
* **Priority Management**: Adjust evaluation precedence across multi-tenant policy rings.
* **Live Evaluator**: Test expressions with custom JSON request and resource contexts.

### 6. Enterprise Federation Studio (`/enterprise` — Hermes Engine)
* **SAML 2.0 Identity Providers**: Configure Okta, Azure AD (Entra ID), or Google Workspace metadata.
* **SCIM 2.0 Inbound Provisioning**: Monitor continuous directory synchronization webhooks (RFC 7643 / RFC 7644).

### 7. Fleet & Topology Studio (`/fleet` — Argus Engine)
* **Instance Registry**: Monitor live heartbeats, latencies, and versions for all engines.
* **Topology Visualizer**: Interactive network dependency graph.
* **Token Minting Wizard**: Issue `aet_...` enrollment tokens scoped by engine type and environment.

## 📜 Live Audit Trail & Verification (`/audit`)

* **Zero-Mock Real Data**: Directly queries Argus's `/v1/audit` endpoint and PostgreSQL `audit_records` table.
* **Filter by Actor, Resource & Outcome**: Fast search across operations (`LOGIN`, `MINT`, `CREATE`, `UPDATE`, `DELETE`).
* **Diff Viewer**: Displays before/after state JSON diffs with automatic masking of secrets and passwords.
* **Cryptographic Verification Button**: Triggers `/v1/audit/verify` to confirm that all SHA-256 links in the Merkle chain remain 100% intact.
* **Export**: One-click download of audit logs in CSV (for compliance audits) or JSON.

## 🛡️ Live Compliance Dashboard (`/compliance`)

* **Continuous SOC 2 & ISO 27001 Evidence**: Live aggregation from Argus (`/v1/compliance/evidence`).
* **Automated Controls**:
  - `CC6.1`: Cryptographic Audit Trail Integrity & SHA-256 Merkle Chaining.
  - `CC6.2`: Administrative Operator Access & Credential Review.
  - `CC7.1`: Fleet Infrastructure Health, Continuous Heartbeats & Inventory.
* **Evidence Package Generator**: Bundles audit logs, operator access lists, and cryptographic proof into an auditor-ready package.

## 🔔 Real-Time Fleet Notification Center

The bell icon in the Console header provides live cluster notifications:
* **Token Mints & Enrolments**: Instant notice when new tokens are minted or engines join the cluster.
* **Security Alerts**: Notifications for failed enrollment attempts, token revocations, or instance heartbeats missed.
* **Persistent Read State**: Read/dismissed statuses are stored in browser `localStorage`.
